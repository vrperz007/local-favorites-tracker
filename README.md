# local-favorites-tracker
Save the places worth going back to, then find them again.

A small web app for keeping track of favorite local spots (coffee shops, restaurants, parks and more) with ratings and notes. Built with plain HTML, CSS and JavaScript.

Features:
Add favorites with a name, category, 1–5 star rating and optional notes
Search by name or notes as you type
Filter by category: Coffee, Restaurants, Parks, Shopping, Entertainment
Delete a favorite, with a confirmation prompt
Saved automatically in the browser with localStorage, so favorites are still there after a refresh
Responsive layout: one column on phones, a card grid on tablets and larger screens
Accessible form: labeled inputs, required-field indicators and visible keyboard focus.
